# Go Social Web UI

This React app lives in the same repository as the Go backend.

## Page flow

1. `/register` - create account (`POST /v1/users/register`)
2. `/activate` - activate account (`POST /v1/users/activate`)
3. `/login` - login (`POST /v1/users/login`)
4. `/horizon` - your feed with comment CRUD
5. `/studio` - create post + view/update/delete your own posts
6. `/atlas` - user search with pagination + follow/unfollow

## APIs consumed

- `GET /v1/users/feed`
- `POST /v1/posts` (supports optional `image_url`)
- `GET /v1/posts/me`
- `PUT /v1/posts/{postId}`
- `DELETE /v1/posts/{postId}`
- `POST /v1/comments/`
- `GET /v1/comments/post/{postId}`
- `PUT /v1/comments/{commentId}`
- `DELETE /v1/comments/{commentId}`
- `GET /v1/users?page=&page_size=&name=`
- `POST /v1/users/{userId}/follow`
- `POST /v1/users/{userId}/unfollow`

## Run locally

```bash
npm install
npm run dev
```

By default, Vite proxies `/v1/*` to `http://localhost:8080`.

## Notes

- Activation token is generated by backend and logged by the API server during registration.
- JWT token from login is stored in `localStorage` and sent as `Authorization: Bearer <token>`.
